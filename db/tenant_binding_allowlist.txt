# Allowlist for scripts/ci/check_tenant_binding.py (ADR-0001 SEC-1 §3 point 4).
#
# Format (tab-separated): <class>\t<matcher>\t<justification>
#   class   = permanent | transitional
#   matcher = an exact Go function/method name (e.g. "Migrate"),
#             an exact file path (e.g. "internal/alertcase/postgres.go"),
#             or a path prefix ending in "/" (e.g. "db/migrations/")
#
# Every entry needs a one-line justification. The check fails on any entry
# that no longer resolves to real code: a permanent entry must name a
# function that exists (or a path that exists); a transitional entry must
# still be the reason a real call site is allowed through, so the list
# shrinks as call sites move behind internal/tenantsql instead of quietly
# accumulating cruft.
#
# PERMANENT -- never expire, per ADR §3.
permanent	Migrate	D1/ADR §3: runs schema DDL as owl_migrator; never bound to a tenant.
permanent	Ping	D1/ADR §3: issues SELECT 1; touches no tenant-scoped relation.
permanent	db/migrations/	ADR §5: the 014 migration backfill/policy DDL runs directly as owl_migrator, outside any Go seam.
permanent	internal/integrationtest/tenant_isolation_test.go	ADR §8: the two-tenant suite deliberately issues raw SQL via psql to verify what Postgres RLS/WITH CHECK enforce directly, independent of the Go seam -- it must not route through tenantsql, since the property under test is the database's own enforcement, not the seam's.
#
# TRANSITIONAL -- empty. The seam PR (internal/tenantsql, ADR §3) has
# adopted WithTenant at every sink call site that was seeded here by the
# gate PR; a transitional entry surviving the seam PR is a bug the check
# itself catches, because the call site it protects will have moved.
